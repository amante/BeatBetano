# Experimental joint NFL BetBuilder

This independent research module does not alter `nfl_hoy`, official probabilities,
frontend prices or promotion settings. It reuses multisport lineage verification,
canonical input fingerprints and calibration scoring. No odds are accepted as
required model inputs. Real fitted parameters and source authenticity still
require independent review.

Run from repository root (Python >=3.9):

```
python -m nfl.betbuilder_joint --input experiment.json --output joint.json --samples 20000 --seed 42
python -m nfl.betbuilder_joint --input archived_builders.json --output reliability.json --audit
```

`experiment.json` has `config` and `legs`. See `nfl/tests/test_betbuilder_joint.py`
for a complete **synthetic** input fixture. Config contains:

- Existing pregame `manifest` with observation timestamps/content hashes and
  `odds_used_in_model: false`; `teams`: two distinct team IDs.
- `players`: unique player_id, team, position (QB/WR/TE/RB/DEF), resolved status
  (available/out), snap_share, catch_rate, explosive_rate, target_weight,
  carry_weight, tackle_weight, yards_per_catch, yards_per_carry. Supply complete
  opportunity coverage, including residual players rather than only selected props.
- `scenarios`: sports-estimated weights summing to one, named game_script,
  shared pace_factor, weather_factor, tackle_probability, team-specific expected
  plays and pass_rate. Include leading/trailing scenarios and forecast weather
  uncertainty. Weights/parameters must be frozen before outcomes, never chosen to
  match a requested payout. No default fitted NFL estimates are provided.

A draw samples one whole game script, common pace/weather, each team's plays and
participation, then passes/runs. Targets compete for receiver participation;
catches and receiving yardage generate QB passing yardage from the same events.
Carried volume shares the same finite participation budgets. Defensive snaps
use opposing offensive plays; tackles depend on opposing volume. Targets plus
carries cannot exceed the sampled player's snaps, receptions cannot exceed targets,
and passing yards equal team receiving yards. This is a simplified opportunity
model, not an NFL play-by-play engine: no sacks, penalties, TDs, turnovers,
negative-yard plays, assisted tackles, overtime, field-position limits or QB
substitutions. Participation budgets approximate timing and do not reconstruct
which eleven players share every play. Full-game QB and resolved availability
are required; uncertain availability needs separate externally weighted scenarios.

Each leg has player_id, market, op and value. Supported numerical markets are
pass_yards, receiving_yards, receptions, rush_yards, carries, tackles, snaps,
targets; use ge/le for inclusive thresholds. Exactly 1..13 unique legs are allowed.
`longest_reception_50_plus` accepts **only** `op: "is"` and a JSON boolean value.
It is an event generated by at least one 50+ catch, not a continuous yardage
forecast or a probability for average receiving yards. Non-explosive catch lengths
are capped below 50; explosive lengths are sampled from 50..99. These distribution
assumptions need historical estimation and ablation before use.

Output contains joint and marginal probabilities, the independence comparator,
hit-pattern distribution, reproducibility hashes, seed and Wilson Monte Carlo
interval. Zero observed hits is not proof of impossibility. This interval covers
sampling error only, not parameter uncertainty or model misspecification.

Historical audit records contain event_id, builder_id, season, manifest,
training_cutoff_utc, settled_at_utc, outcome (all legs hit: 0/1), joint_probability
and independence_probability. Audit emits per-season Brier, log loss and ten
reliability bins. It rejects duplicates, invalid probabilities, non-pregame
snapshots and calibration training after freeze. If a calibrator is fitted,
fit it only on earlier settled games, preserve its training IDs/hash, and use
untouched later seasons. Keep all builders from one game together; cluster
uncertainty by game/season. The audit alone does not certify authenticity,
independent selection or calibration. `calibrated` stays false.

Validation includes nesting (joint equals the stricter event, differs from the
independence product), contradictory binary legs, 13-leg bounds, zero-hit
uncertainty, reproducibility, conservation and temporal audit rejection. Synthetic
contracts demonstrate mathematical behavior, not predictive improvement. Historical
NFL prop outcomes and authentic archived pregame parameter snapshots are not supplied
by this PR; no performance or calibrated joint-probability claim is made.
