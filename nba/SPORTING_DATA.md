# NBA Sporting Data — live availability acquisition

The daily NBA availability sidecar now captures the latest timestamped PDF linked by the [official NBA injury report](https://official.nba.com/nba-injury-report-2026-27-season/) and the supplementary ESPN injury feed. It parses explicit player/team/status rows and team-level `NOT YET SUBMITTED` markers, then reconciles report rows to the current ESPN roster using an exact normalized player name within the reported team. Each matched claim retains the PDF URL, report timestamp, retrieval timestamp, page, line, and source text. Rows without one unique roster match remain unresolved.

Only rows for the fixture's New York league date and matching matchup are eligible, and the report must be published and downloaded before tipoff. A report collected after the frozen forecast cannot rewrite that forecast. Explicit `Out` statuses feed the existing experimental minutes redistribution; `Questionable`, `Doubtful`, and `Probable` remain uncertain, and unlisted players remain unknown. A team marked `NOT YET SUBMITTED` is not treated as healthy.

This closes part of the status-source gap, but does not verify starting fives, supply every player's availability, estimate player impact on scoring, or calibrate a win-probability adjustment. The report and scenarios remain research evidence; production probabilities are unchanged. Betting odds are not used as model inputs. NFL unchanged.
